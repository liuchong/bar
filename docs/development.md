# 构建与开发

[返回 README](../README.md) · [使用指南](usage.md) · [系统图标](system-icons.md)

## 环境要求

- 运行环境：macOS 27.2 或以上；应用启动时检查系统版本。
- 构建环境：包含 macOS 27 SDK 的 Xcode、Swift 6.2 或以上。
- Swift Package Manager 工程，无第三方运行时依赖。

## 构建、签名与安装

仅构建应用：

```sh
bash scripts/build.sh
open dist/Bar.app
```

输出为 `dist/Bar.app`。未指定签名身份时，构建脚本使用临时签名，适合检查构建结果。

日常使用建议安装并使用稳定签名。更新前先从 Bar 菜单退出正在运行的版本，再执行：

```sh
bash scripts/install.sh
open -a Bar
```

安装脚本会自行构建，默认选择本机可用的 Apple Development 签名身份，安装到系统应用程序目录并登记应用。找不到签名身份时会停止并给出提示。

| 环境变量 | 作用 |
| --- | --- |
| `BAR_SIGN_IDENTITY` | 指定代码签名身份。 |
| `BAR_INSTALL_DIR` | 指定安装目录。日常使用建议保留默认位置。 |

修改安装目录后，应直接打开该目录中的应用，避免启动同名副本。临时签名或频繁更换签名身份可能导致系统重新要求授权。构建、图标生成和测试应设置合适的时间、并发及资源上限。

## 实现约束

### 先发现，再收纳

保存的规则不能提前隐藏尚未发现图标的新进程。当前运行进程与缓存记录按进程身份核对，新发现的项目进入位置整理和图像读取队列；空结果、位置整理失败或已授权但图像仍缺失时，保留原生显示。

配置使用原子替换写入，读取失败时保留原文件并提示。应用退出、暂时不提供图标或系统图标管理被关闭，都不应清除保存的规则。

### 保持菜单栏稳定

日常展开、收起和图像刷新不改变原生显隐配置。抽屉显示期间锁定定位基准；下方左右两组共用 Bar 入口中心，保持相邻，避免被原生右侧图标推到屏幕边缘。向左展开跳过摄像头缺口，一行空间不足时换到下一行。

初始化、规则变化与新项目发现时允许整理原生位置。整理等待鼠标空闲，短暂隐藏拖动轨迹，在结束、取消、暂停和退出时释放输入并恢复鼠标。用户输入打断操作时停止继续整理。原生辅助功能点击区域可能少量重叠，排序使用图标中心判断。

### 使用真实图像与原生操作

图像仅保存在内存中。启动时在收纳前读取图标，已收纳项目沿用最近一次图像，不通过反复恢复原生项目来刷新。下方图标按背景亮度选择黑白，使用缓冲避免在中间亮度反复切换。

下方抽屉使用 `NSGlassEffectView` 的实时透明玻璃；背景浓度从完全透明连续过渡到模糊，再在末段加入系统实色。默认浓度 65%，设置预览复用同一套材质。浓度滑杆使用原生 `NSSlider` 绘制每 5% 的刻度，点击按最近刻度吸附，拖动和松手保留连续值。浓度变化独立保存，不触发原生排序。

背景外露底角半径上限为 10 点，底边和左右外缘的透明过渡宽度为 1.5 点。圆角和渐变遮罩只施加在材质容器，图标及点击区域保持完整。相邻左右栏的接合边保持平直，避免中间出现淡化缝隙；向左展开不添加背景和边缘效果。

抽屉接收非激活状态下的首次点击。点击项目后，等待系统确认恢复原图标，再重新查询辅助功能对象与安全坐标；没有界面响应时，对原图标尝试一次原生点击。普通应用窗口的打开代表一次操作完成，只有临时菜单或弹出面板保持菜单会话，避免阻挡后续点击。

设置中的原生下拉菜单结束跟踪后才更新分组，避免在菜单仍开着时移除控件。原生整理只恢复由该操作带走的设置焦点，不抢占用户选择的无关应用。

## 测试与诊断

```sh
# 全部自动测试
swift test -j 2

# 配置与显隐策略
swift test -j 2 --filter ConfigurationIntegrationTests

# 发现时序与进程重启
swift test -j 2 --filter DiscoveryIntegrationTests

# 原生菜单交互与生命周期
swift test -j 2 --filter MenuInteractionIntegrationTests
```

通过构建产物诊断系统、辅助功能、图像权限和显隐接口状态，不修改图标：

```sh
dist/Bar.app/Contents/MacOS/Bar --diagnose
```

运行诊断前先退出已经运行的 Bar，避免同时保留另一个应用实例。

当前自动测试共 **51 项**：41 项配置、策略、图像、布局和交互组合测试，10 项关键状态保护测试。覆盖收纳规则持久化、左右栏独立行为、系统开关恢复、发现前放行新进程、摄像头缺口和外接屏坐标、图像权限、非激活首次点击、普通窗口与临时菜单的生命周期区分，以及背景浓度的端点、点击吸附、连续拖动和保存恢复。
