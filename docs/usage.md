# 使用指南

[返回 README](../README.md) · [系统图标](system-icons.md) · [构建与开发](development.md)

## 首次设置

1. 从应用程序目录打开已安装的 Bar。
2. 在“通用”页允许辅助功能，以便管理和操作菜单栏图标。
3. 允许屏幕录制，以便读取原菜单栏图像；未授权时，抽屉会提供图像授权入口。
4. 进入“图标”页，选择每个项目的分区与去向，再设置所属抽屉的开合方式。

屏幕录制权限用于图像读取，不是收纳规则生效的前提。Bar 不录音、不联网，图像只在内存中处理。界面会跟随系统外观，无需单独设置深色或浅色模式。

## 选择图标放在哪里

每项提供两个并排的选择：

| 设置 | 选项 | 作用 |
| --- | --- | --- |
| 分区 | 左栏、右栏、忽略 | 决定由哪一栏管理；忽略时交给系统显示。 |
| 图标去向 | 菜单栏常显、收纳到抽屉 | 决定原生图标一直留在菜单栏，还是通过抽屉使用。 |

“忽略”项目单独列出，并显示“系统原样”。忽略不会删除此前保存的分区和图标去向，重新加入管理后可以继续使用。

“收纳到抽屉”仍然可以打开原来的功能：先点击 Bar 展开抽屉，再点击其中的图标。也可以在设置列表中点击运行中收纳项的应用图标，预览它的菜单或窗口。

例如，把常用项目设为“右栏 + 菜单栏常显”，其他项目设为“左栏 + 收纳到抽屉”。这样右侧顺序固定，左侧按需展开。

## 设置抽屉如何开合

在“图标”页的左栏、右栏开头，分别设置所属抽屉。这些选项只影响收纳项，不会把常显图标一起收起。

| 抽屉开合 | 行为 |
| --- | --- |
| 点击展开 / 收起 | 点击菜单栏的 Bar 图标展开，再点一次收起。 |
| 悬停自动展开 / 收起 | 鼠标靠近后展开，离开后延时收起，也支持点击切换。两栏共用延时设置。 |
| 抽屉保持展开 | 本栏收纳项持续显示；切换为其他开合方式后才能收起。 |

左栏可以沿菜单栏向左展开，也可以向下展开一行；右栏固定在菜单栏下方展开，避开右侧原生图标。右键 Bar 可单独展开、收起某一栏，或统一切换两栏的开合方式。

自动模式在操作菜单或打开设置时保持当前抽屉状态。两栏开合方式不同、或其中一栏保持展开时，点击 Bar 只切换允许收起的栏目。

## 分组与排序

原生菜单栏按下面的分组整理：

```text
左栏常显 → Bar → 右栏常显 → 忽略与系统固定入口
```

左右栏独立排序。设置列表中的上下按钮调整顺序，抽屉内也可以拖动排序。同一应用的多个菜单栏图标统一管理；常显与收纳项目各自排列，收纳项不会插入原生常显图标之间。

忽略项和系统固定入口保留组内相对顺序，不提供自定义排序。排序未完成时，界面会给出提示，可关闭菜单后点击“重新整理菜单栏顺序”重试。

日常展开与收起只改变抽屉自身，保留 Bar 入口及原生右侧区域的位置。首次收纳、新项目出现或规则变化时，可能需要整理原生位置；整理会等待鼠标空闲，失败的项目暂时保留原生显示。系统改变图标宽度或切换屏幕时，原生菜单栏仍可能重新排版。

## 暂停、关闭与退出

| 操作 | 结果 |
| --- | --- |
| 暂停图标管理 | 临时释放 Bar 的显隐限制，保留所有规则；恢复管理后重新应用。 |
| 关闭设置窗口 | 菜单栏管理继续运行，Dock 图标隐藏。再次打开 Bar 可回到设置。 |
| 退出 Bar | 结束程序并释放显隐限制，已保存规则不清除。 |

设置窗口打开时，Bar 作为普通应用显示 Dock 图标。分区、图标去向和顺序会自动保存到用户应用支持目录中的 `Bar/settings.json`。读取配置失败时会提示原因，并保持图标可见。

系统图标有单独的管理开关；关闭它只停用系统项目的规则，详见[系统图标](system-icons.md)。

## 常见问题

### 应用在运行，为什么显示“等待菜单栏图标出现”？

应用在运行不代表已经创建菜单栏图标。也可能是图标尚未被系统暴露给辅助功能接口。Bar 会保留规则，并在发现当前进程的图标后再整理和收纳；不会提前将未识别的项目隐藏。

如果图标已经存在但仍未识别，可点击“刷新图标”。首次发现、位置整理或图像读取未完成的项目会暂时保留原生显示。应用已经退出或不提供菜单栏图标时，抽屉不会生成一个代替它的启动图标。

### 有项目但没有图像，怎么办？

先检查屏幕录制权限，再点击“刷新图标”。若初始化时未能取得图像，可以暂停管理、刷新一次，再恢复。未取得图像时不会用彩色应用 Logo 冒充原菜单栏图标。

### 为什么数字或状态不是实时变化的？

抽屉使用真实菜单栏图像的快照。收纳后的图标保留最近一次读取的图像，不为刷新而反复恢复原生项目，因此计数、文字和动画不保证实时更新。

### 点击图标没有打开菜单，怎么办？

确认辅助功能权限有效，并等待位置整理完成后重试。有些应用点击后打开的是普通窗口，而不是下拉菜单，这取决于原图标的行为。若界面提示无法打开，可关闭其他菜单后刷新；系统自身禁用或无法操作的项目不能保证被恢复或打开。
