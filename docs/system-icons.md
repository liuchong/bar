# 系统图标

[返回 README](../README.md) · [使用指南](usage.md) · [构建与开发](development.md)

## 管理开关

在“图标”页的“系统图标”分组中开启**管理系统图标**。此开关默认关闭，与第三方应用的管理规则独立。

关闭开关只停用系统图标规则，不删除每项保存的分区、去向或顺序。重新开启后恢复原有选择，规则也会在 Bar 重启后保留。

## 项目范围

系统列表先显示可管理项，最后显示系统固定入口与未识别项；只有系统实际提供的项目才会被发现。

| 类型 | 项目 | 行为 |
| --- | --- | --- |
| 已映射的可管理项 | 电池、蓝牙、显示器、输入法、声音、Wi-Fi、屏幕镜像 | 可以选择分区、常显或收纳，并管理排序。 |
| 系统固定入口 | 时钟、控制中心 | 保持系统显示，不提供收纳和排序操作。 |
| 未识别项 | 尚无对应管理策略的系统入口 | 保持原样，不假定具备可管理能力。 |

输入法按钮有时没有标准的系统标识，Bar 会结合已启用的系统输入源识别它。系统图标按各自身份管理，不会因为共同属于系统宿主而被合并为一个应用。

“已映射”表示代码中存在对应策略，不代表所有项目和系统组合都已完成实机验收。目前已实机验证 Wi-Fi 的收纳与常显、电池的右栏常显，以及系统总开关关闭、重开后的规则恢复；输入法的识别已确认，原生菜单打开尚未完整验证。

## 与第三方图标一起排列

系统可管理项采用同一套“左栏 / 右栏 / 忽略”和“菜单栏常显 / 收纳到抽屉”规则。原生排列为：

```text
左栏常显 → Bar → 右栏常显 → 忽略与系统固定入口
```

Bar 通过整理自己的入口与常显项目形成分组。忽略项和系统固定入口本身不被拖动，保留它们之间原有的相对顺序。

## 当前边界

- **依赖当前系统接口**：显隐使用 macOS 的私有菜单栏服务，可能随系统更新变化。服务不可用、调用失败或辅助功能未授权时，Bar 会释放限制并保留原生显示。
- **不能创建系统未提供的图标**：系统设置中未显示、应用尚未创建或未向辅助功能暴露的项目，不能由 Bar 强行生成。
- **不能保证所有项目可操作**：没有辅助功能操作、被系统禁止显示或运行副本未被正确登记的项目，可能无法恢复、排序或打开。
- **同一应用统一管理**：第三方应用的多个图标使用同一应用身份执行显隐规则；系统项目使用独立的项目白名单。

如果忽略的应用运行副本与系统登记不匹配，Bar 会提示原因并保持图标可见，避免连带隐藏该应用。建议从应用程序目录启动安装后的版本。

## 外观与稳定性

抽屉读取真实菜单栏图像。单色图标随背景选择黑色或白色，原本为彩色的状态图标保留其色彩。向左展开沿用现有菜单栏背景；下方附属条与系统菜单栏保持间隔，支持“透明 / 模糊 / 实色”连续调节，并采用底角圆角与极窄的边缘淡化。调节方式见[下方抽屉背景](usage.md#下方抽屉背景)。

收纳项先完成发现、位置整理和图像读取，再隐藏原生项目。打开原菜单时，只恢复已经核实位于 Bar 左侧的项目，避免把图标插入固定的右侧区域。更多实现与验证范围见[开发指南](development.md)。
