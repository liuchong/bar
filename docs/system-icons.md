# 系统图标与管理状态

目标：系统图标管理可开关，关闭不删除规则，重开完整恢复；分区和显示状态使用两个并排下拉框，并修正切换管理时的异步交互。

## 行为

- 分区下拉框：左栏、右栏、忽略。忽略只停用规则，保留显示选择和原分区。
- 显示状态下拉框：显示、隐藏。显示保留原生菜单栏图标并排序；隐藏收进对应栏的抽屉，按该栏显隐方式展开。
- 管理系统图标默认关闭。系统规则与开关分别保存，关闭仅使规则不生效，不清空分区、显示状态或顺序。
- 时钟、控制中心保留系统固定入口；未识别的系统项目保持原样，不能假装支持。
- 原生图标移动和截图排队执行；菜单关闭后保存选择、更新分组，再整理。快速改动使旧操作失效；暂停、退出释放所属输入。

## 实现路径

- `BarCore/Configuration`：总开关、忽略标记、保存值与生效值分离。
- `BarCore/SystemItemPolicy`：当前系统已核对的系统项目编号及固定入口。
- `Bar/Accessibility`：系统图标读为具备稳定身份、原生元素与坐标的项目。
- `BarNative`：独立传入系统项目白名单，不改变各项设置。
- `Bar/AppModel`：立即保存选择、串行取消过期操作、系统开关与可见性接线。
- `Bar/Views`：并排下拉框、系统总开关、关闭时显示已保存规则。

## 设置窗口与附属条修正

- 设置打开时显示 Dock 图标，关闭窗口后菜单栏管理继续运行；实机关闭和重开前后进程相同。
- 原生下拉菜单关闭后才保存选择和移动分组，避免在菜单跟踪期间移除控件；忽略→右栏隐藏→显示已实机验证。
- 自动原生整理仅恢复被该操作带走的设置焦点，不抢占用户切换到无关应用的焦点。
- 下方左右两组共用 Bar 入口中心作为边界，彼此相邻，不被原生右侧图标推远。
- 已安装但未运行的应用及其辅助进程读取名称、图标；未找到的应用保留规则并显示系统通用图标。
- Dock 和菜单栏使用同一抽屉矢量，分别生成各目标尺寸，最大 1024 像素。

新增组合测试覆盖菜单跟踪期间延后更新分组、离线应用与嵌套辅助程序的元数据读取，以及下方两组相邻且不重叠的布局。

本轮自动验证为 33 项集成测试和 8 项保护测试。实机系统项目使用 Wi-Fi 与电池；其余已映射项目尚未逐项验证。未找到 Bar 崩溃报告，不能确认用户此前遇到的是进程崩溃；修正后的实机切换中未出现进程退出或设置窗口自动隐藏。

## 分组、输入法与交互

- 系统列表先列可管理项目，固定和未知入口最后列出，仍保留各组原先保存的顺序。
- 原生菜单栏为左栏常显、Bar、右栏常显、忽略及固定入口。通过移动 Bar 入口与常显项目形成分组，忽略和固定入口不被拖动，保留它们的相对顺序。
- 系统输入源在主线程读取，作为辅助功能扫描的快照；无标识的输入法按钮使用已启用输入源的名称识别。系统宿主不再作为普通应用重复扫描。
- 系统辅助功能的点击区域可以少量重叠，使用图标中心核对原生顺序，避免误报后重复整理。
- 原生拖动等待鼠标空闲，隐藏短暂的拖动轨迹；正常结束、取消、暂停及退出均释放输入、重新关联鼠标并恢复光标。鼠标活动中止事务，不继续争抢。
- 离线应用识别支持任意段数的标识、辅助程序及系统未登记的标准应用目录。失败按间隔重试，不永久缓存失败。找不到时保留管理规则并明确提示。
- 通用页的“左栏抽屉方向”与两栏“抽屉展开方式”只作用于收纳项。图标页“显示”仍表示原生常显，“隐藏”表示收进抽屉；右栏抽屉固定向下展开。暂停全部管理与系统图标开关作用范围不同，均保留规则。
